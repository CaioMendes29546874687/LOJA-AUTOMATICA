# Checklist de aceite inicial

- [ ] `npm install` conclui sem erro.
- [ ] `npm run build` conclui sem erro.
- [ ] `GET /api/health` responde `ok: true`.
- [ ] `GET /api/products` retorna seis itens de demonstração sem banco.
- [ ] Página inicial adapta-se a celular e desktop.
- [ ] Painel `/admin` identifica claramente o modo de demonstração.
- [ ] Nenhuma compra ou cobrança real pode ser efetuada nesta versão.
- [ ] Antes de produção: autenticação, privacidade, pagamentos, webhooks, fornecedor, logística, testes e política de devolução.
